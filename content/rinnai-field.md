# Rinnai → EctoControl → USR-W610 → Home Assistant

Схема подключения:

```text
Rinnai → EctoControl → RS-485 → USR-W610 → Wi‑Fi → Home Assistant
```

Rinnai использует собственную цифровую шину, не OpenTherm. В Modbus её преобразует адаптер EctoControl.

## Что взять с собой

- адаптер EctoControl для Rinnai со всеми комплектными проводами и клеммниками;
- USR-W610 с антенной и блоком питания;
- стабилизированный блок питания **12 В DC** для EctoControl;
- короткую витую пару для RS-485 `A/B` и провода питания (Ethernet-кабель не нужен);
- маленькую отвёртку;
- мультиметр;
- ноутбук или телефон;
- название и пароль сети на объекте Wi‑Fi **2,4 ГГц**;
- доступ к роутеру и Home Assistant.

> EctoControl требует питание 7–14 В DC. Использовать отдельный БП 12 В, не 24 В. Не брать питание с платы Rinnai или с линии штатной панели: для RB‑367RMF не подтверждён отдельный 12-вольтовый выход с допустимой для адаптера нагрузкой.

## Настройка на объекте

### 1. Подключить EctoControl к котлу

1. Записать рабочие уставки и допустимые пределы температур своей системы. Обесточить котёл, EctoControl и W610 перед любыми перестановками проводов. Работу внутри котла при отсутствии опыта поручить специалисту.
2. Сфотографировать исходное подключение платы и штатной панели. Убедиться, что адаптер именно для Rinnai (ES-BRRI-01); если разъёмы не совпадают, не вставлять их наугад.
3. Найти провод цифровой шины, идущий от платы Rinnai к штатной панели.
4. Разъединить линию панели и комплектным кабелем соединить соответствующий разъём платы котла с входом **КОТЕЛ** EctoControl.
5. Штатную панель подключить к входу **ПАНЕЛЬ** EctoControl для возможности возврата управления.
6. Использовать комплектные разъёмы адаптера и ориентироваться по надписям **КОТЕЛ/ПАНЕЛЬ**, а не по цвету или форме разъёма.

Получится:

```text
плата Rinnai → КОТЕЛ [EctoControl] ПАНЕЛЬ → штатная панель Rinnai
```

### 2. Соединить EctoControl с USR-W610

На кабеле/разъёме **ДОП** EctoControl:

| EctoControl | Подключение |
|---|---|
| `+12V` | плюс блока питания 12 В |
| `GND` | минус блока питания |
| `A` | `A` или `485+` на W610 |
| `B` | `B` или `485−` на W610 |

Типичные цвета комплектного кабеля EctoControl: жёлтый/красный — `+12V`, белый — `GND`, зелёный — `A`, коричневый/синий — `B`. Проверять по маркировке контактов.

1. Подключить `A` и `B` к двухконтактному разъёму **RS485** на W610.
2. Разъём DB9 **RS232 не использовать**.
3. Подключить вход питания EctoControl к внешнему БП 12 В. Именно вход питания `+12V/GND` не соединять с платой Rinnai; вход **КОТЕЛ** соединяется с её цифровой шиной по шагу 1.
4. Подключить питание W610 согласно напряжению, указанному на его корпусе или штатном блоке питания.
5. Проверить напряжение и полярность выхода БП до подключения к устройствам. Антенну W610 установить перед подачей питания. Котёл пока оставить обесточенным.

### 3. Настроить USR-W610 по Wi‑Fi

1. Включить W610 и EctoControl.
2. На ноутбуке или телефоне подключиться к сети вида `USR-W610_xxxx`; согласиться остаться в сети без интернета.
3. Открыть в браузере `http://10.10.100.254`.
4. Заводской логин и пароль обычно `admin` / `admin`.
5. Сначала настроить последовательный порт и Socket A по таблице ниже; переход в **STA** выполнить последним, поскольку после применения исчезнет точка доступа W610.
6. Названия пунктов зависят от прошивки. Установить:

   | Параметр W610 | Значение |
   |---|---|
   | Work/Data mode | `Modbus TCP <=> Modbus RTU` |
   | Socket A | `TCP Server` |
   | Local port | `502` |
   | Serial interface, если есть такой выбор | `RS485` |
   | Baud rate | `19200` |
   | Data bits | `8` |
   | Parity | `None` |
   | Stop bits | `1` |
   | Flow control | `None` / `NFC` |

7. Сохранить параметры, отключить добавочные пакеты **Heartbeat/Registration/Identity**, если включены. Затем выбрать **STA**, сеть 2,4 ГГц с **WPA2-PSK/AES**, указать пароль и автоматическое получение IP (**DHCP**). Сохранить и перезагрузить W610.
8. Снова подключиться к обычной сети на объекте Wi‑Fi.
9. В списке клиентов роутера найти IP W610 по MAC с наклейки и закрепить его в DHCP. HA должен иметь доступ к этому адресу: гостевая сеть с изоляцией клиентов не подходит. Порт 502 в интернет не открывать.

Записать:

```text
IP W610: ____________________
Порт: 502
```

### 4. Добавить интеграцию в Home Assistant

Если `ec-adapter` уже установлен и HA после установки перезапущен, начать с шага 4. Текущая интеграция требует HA 2025.10.0 или новее.

1. Открыть **HACS** и найти `ectoControl Adapter`.
2. Скачать интеграцию. Если её нет в поиске, открыть меню HACS → **Пользовательские репозитории**, добавить URL с типом **Интеграция**, затем найти и скачать её:

   ```text
   https://github.com/sokolovs/ec-adapter
   ```

3. Перезапустить Home Assistant.
4. Открыть **Настройки → Устройства и службы → Добавить интеграцию**.
5. Выбрать **ectoControl Adapter / Адаптер ectoControl**. Если устройство уже добавлено, открыть его настройки вместо создания второго подключения.
6. На первом экране указать имя, таймаут, тип и Slave ID; на следующем — хост и порт:

   | Параметр HA | Значение |
   |---|---|
   | Имя | `Rinnai EctoControl` |
   | Тип подключения | `TCP` |
   | Host | IP-адрес W610 |
   | Port | `502` |
   | Slave / Unit ID | `240` |
   | Timeout | `5` секунд |

7. Сохранить. Проверка читает uptime самого адаптера — котёл для неё включать не требуется. `configuration.yaml` редактировать не нужно; второй Modbus-клиент к этому W610 не запускать.

Если адаптер EctoControl раньше программировался в фирменной системе, его адрес мог измениться с `240` на число `1–32`.

### 5. Проверить работу

1. В HA открыть `Rinnai EctoControl`: проверить версию и «Наработку»/время загрузки адаптера.
2. До включения котла проверить управляющие значения и привести целевые температуры и пределы к записанным настройкам своей системы. **Интеграция может автоматически записывать их при восстановлении связи**; её начальные пределы (отопление 40–80 °C, ГВС 40–55 °C) не обязательно подходят вашей системе.
3. Выбрать **Тип подключения → Адаптер** (`adapter`), затем включить котёл. Проверить «Связь с котлом» и фактическую температуру теплоносителя. Если «Адаптер» уже отображается, но связи нет, выбрать «Панель котла», затем снова «Адаптер», чтобы явно отправить команду.
4. Задать **Целевую Т. теплоносителя** в допустимом для своей системы диапазоне. Затем выбрать **Режим работы → Отопление** (`heating_only`) либо **Отопление + ГВС** (`heating_dwh`); для второго варианта задать также целевую температуру ГВС.
5. Наблюдать фактические температуры и работу котла. Число в поле управления — отправленная установка, а не подтверждение её принятия котлом. Проверить возврат управления через **Тип подключения → Панель котла**; в этом режиме отсутствие связи адаптера с котлом ожидаемо.
6. Не нажимать **Сбросить ошибки котла/Перезагрузить адаптер** ради проверки и не менять модуляцию. Перед отъездом проверить поведение при потере Wi‑Fi/HA и восстановлении связи; до проверки оставить штатное управление панелью.

## Если связи нет

Проверять по порядку:

1. W610 виден в списке клиентов Wi‑Fi роутера.
2. IP W610 и порт `502` правильно указаны в HA.
3. На W610 выбран `Modbus TCP <=> Modbus RTU`, а в HA — `TCP`. Если используется `Transparent`, в HA нужен **RTU over TCP**.
4. Установлено `19200, 8N1, RS485`.
5. Slave ID равен `240`.
6. EctoControl получает 12 В.
7. Если ответа нет, отключить питание и один раз поменять `A` и `B` местами.
8. Если uptime появился, но связи с котлом нет — проверить разъёмы **КОТЕЛ/ПАНЕЛЬ** и `connect type`.

Если котёл ведёт себя необычно, отключить питание и вернуть штатную панель напрямую в исходное состояние по сделанной фотографии.

Проверено по [руководству W610](https://www.pusr.com/download/WIFI/USR-W610-User-Manual-V1.0.1.01.pdf), [руководству EctoControl](https://ectocontrol.ru/download/adapter_opentherm_ebus_navien_user_manual.pdf), [протоколу Modbus](https://ectocontrol.ru/download/protocol_description_modbus_RS485_ectostroy_ru.pdf) и [исходникам интеграции](https://github.com/sokolovs/ec-adapter).
