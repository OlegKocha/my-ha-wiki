Проверьте HTTP-ответ своего внешнего адреса перед настройкой постоянного мониторинга.

## Разовая проверка

Выполните команду в терминале, заменив адрес в примере на свой домен.

```bash
curl -I https://crazedns.ru/ 2>/dev/null | awk '/^HTTP/{print $2}'
```

Команда выводит HTTP-код ответа. Код **200** означает успешный ответ на этот запрос; другой код нужно разобрать отдельно.
