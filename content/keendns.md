Настройте внешний доступ к Home Assistant через KeenDNS и отдельный локальный адрес в мобильном приложении.

## Подготовка адреса Home Assistant

В списке клиентов Keenetic выберите устройство с Home Assistant и закрепите за ним постоянный IP-адрес.

## Выбор порта

Режим KeenDNS влияет на доступные порты. Для прямого доступа и доступа через облако настройки различаются — используйте [инструкцию Keenetic](https://help.keenetic.com/hc/ru/articles/4406428785042-%D0%9F%D1%80%D0%B8%D0%BC%D0%B5%D1%80-%D1%83%D0%B4%D0%B0%D0%BB%D0%B5%D0%BD%D0%BD%D0%BE%D0%B3%D0%BE-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0-%D0%BA-%D1%80%D0%B5%D1%81%D1%83%D1%80%D1%81%D0%B0%D0%BC-%D0%B4%D0%BE%D0%BC%D0%B0%D1%88%D0%BD%D0%B5%D0%B9-%D1%81%D0%B5%D1%82%D0%B8-%D1%87%D0%B5%D1%80%D0%B5%D0%B7-%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81-KeenDNS-%D1%81-%D0%BF%D0%BE%D0%BC%D0%BE%D1%89%D1%8C%D1%8E-%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D1%85-%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D0%BB-NAT).

В исходном примере для облачного режима использовался внешний порт **777** с переадресацией на **8123**. Доступные порты уточняйте по [описанию KeenDNS](https://help.keenetic.ru/hc/ru/articles/360000400919.html).

## Доменное имя

В настройках **Доменного имени** Keenetic добавьте ресурс Home Assistant:

| Поле | Значение из примера |
|---|---|
| Имя | `homeassistant` |
| Доступ | Вариант, доступный в настройках Keenetic |
| Протокол внутреннего ресурса | HTTP |
| Порт | Выбранный на предыдущем шаге, например 777 |

## Мобильное приложение

1. Добавьте в Home Assistant Companion внешний адрес, выданный KeenDNS. Используйте своё доменное имя и порт.
2. Откройте **Настройки → Мобильное приложение → Информация о подключении**.
3. Выберите домашнюю Wi-Fi сеть и укажите локальный адрес, например `http://homeassistant.local:8123`.
4. Предоставьте приложению доступ к геолокации, необходимый для определения сети.

Проверьте подключение отдельно через мобильный интернет и домашний Wi-Fi.
