> [!note] Перед использованием примеров
> Адреса и имена устройств в примерах условные. Замените их значениями своей системы.

Подключение к Home Assistant через WireGuard на роутере Keenetic. Инструкция составлена для KeeneticOS 5.0.11 и приложения WireGuard VPN Server.

### Предварительные требования
- KeeneticOS **5.0.11** (убедитесь, что роутер обновлён).
- **Публичный IP** у роутера или **KeenDNS в режиме «Прямой доступ»** (Direct Access) — без этого внешнее подключение невозможно.
- Локальный IP Home Assistant (например, `192.0.2.10:8123`).
- Сделайте **резервную копию настроек** роутера (Управление → Параметры системы).

### Шаг 1: Установка компонента на роутере
1. Зайдите в веб-интерфейс: `http://my.keenetic.net` или `192.0.2.1`.
2. Перейдите в **Управление → Параметры системы** (или Общие настройки системы).
3. Нажмите **Изменить набор компонентов**.
4. В поиске введите `WireGuard`, поставьте галочку напротив **WireGuard VPN** (или **WireGuard VPN Server**).
5. Нажмите **Обновить KeeneticOS** / **Установить обновления** и дождитесь перезагрузки.

После установки в разделе **Приложения** появится плитка **WireGuard VPN Server**.

### Шаг 2: Настройка WireGuard VPN Server на Keenetic
1. Перейдите в **Приложения → WireGuard VPN Server**.
2. Включите сервер (переключатель **On**).
3. Основные настройки:
   - **Server IP address** (Адрес сервера): укажите, например, `198.51.100.1/24` (любая свободная приватная подсеть, не пересекающаяся с вашей домашней подсетью).
   - **Network access** (Доступ к сети): выберите сегмент вашей домашней сети (где находится HA).
   - **NAT для клиентов**: оставьте включённым (чтобы клиенты могли выходить в интернет через VPN при необходимости).
4. Нажмите **+ Add client** (Добавить клиента):
   - Введите понятное **Имя** (например, `Phone-Android`, `Laptop-Win`).
   - Поставьте галочку **Access** (Доступ).
   - Сохраните.
5. Откроется окно конфигурации клиента:
   - Скачайте `.conf` файл.
   - Или отсканируйте **QR-код** (удобно для телефонов).

Повторите для каждого устройства (отдельный клиент/peer).

### Шаг 3: Настройка клиентов

#### На Android и iOS (телефоны)
1. Установите официальное приложение **WireGuard** (Google Play / App Store).
2. Нажмите **+** → **Scan from QR code** и отсканируйте QR-код из настроек роутера.
3. Или импортируйте `.conf` файл.
4. Включите туннель (переключатель On).

**Параметры ручной настройки:**
- `AllowedIPs = 198.51.100.0/24, 192.0.2.0/24` (ваша домашняя подсеть).
- `Endpoint = ваш_keenetic_ddns:51820` (или порт, который использует сервер).
- `PersistentKeepalive = 25`.

#### На Windows (компьютеры)
1. Скачайте WireGuard с официального сайта: [wireguard.com/install](https://www.wireguard.com/install/).
2. Установите, запустите.
3. **Add Tunnel → Import tunnel(s) from file** (или Create empty и вставьте конфиг).
4. Активируйте туннель.

Пример конфигурации клиента:
```
[Interface]
PrivateKey = REPLACE_WITH_YOUR_PRIVATE_KEY
Address = 198.51.100.2/24
DNS = 192.0.2.1

[Peer]
PublicKey = REPLACE_WITH_SERVER_PUBLIC_KEY
AllowedIPs = 198.51.100.0/24, 192.0.2.0/24
Endpoint = yourdomain.keenetic.link:51820
PersistentKeepalive = 25
```

### Шаг 4: Доступ к Home Assistant
- Подключите VPN на устройстве.
- Откройте браузер и зайдите по **локальному IP** HA: `http://192.0.2.10:8123` (или HTTPS, если настроен).
- В приложении **Home Assistant Companion** используйте локальный адрес — оно автоматически будет работать через VPN.

### Полезные советы и отладка
- **Endpoint**: Используйте ваш DDNS (KeenDNS) + порт WireGuard (обычно 51820 или тот, который указан в настройках).
- **Проверка**: После подключения пингуйте `192.0.2.1` или IP HA из клиента.
- **Firewall / NAT**: В KeeneticOS 5 приложение обычно всё настраивает автоматически. Если нет доступа — проверьте Security level интерфейса WireGuard (должен быть Private) и наличие NAT.
- **Несколько устройств**: Для каждого создавайте отдельного клиента в приложении сервера.
- **Безопасность**:
  - В HA включите 2FA.
  - Используйте сильные ключи (генерируются автоматически).
  - Не открывайте лишние порты.
- **Проблемы**:
  - Не подключается → проверьте публичный IP / KeenDNS Direct Access / порт.
  - Нет доступа к HA → проверьте Allowed IPs в конфиге клиента (должна включать домашнюю подсеть).
  - Статистика подключений: в приложении WireGuard VPN Server есть **Connection Statistics**.

DDNS-имя в поле `Endpoint` используется для поиска внешнего адреса роутера.
