SONOFF SNZB-02DR2 может показывать климат в двух местах одновременно. Крупные цифры — температура и влажность рядом с дисплеем. Две маленькие строки с меткой **EXT1** — показания внешнего датчика. Home Assistant передаёт их на экран через Zigbee2MQTT.

![Дисплей SONOFF показывает 28,5 °C и 40 %, а строки EXT1 — 27,9 °C и 41 %](assets/images/sonoff-snzb-02dr2/display.webp "Реальный экран после настройки. Кадр из обзора Alex Kvazis, 12:10.")

В примере **«датчик-sonoff-snzb-02rd2»** — имя устройства с экраном, а **«внешний датчик температуры»** — устройство, с которого берём температуру и влажность. Инструкция рассчитана на модель **SNZB-02DR2** с прошивкой **1.0.5** и полями **Source 1** в Zigbee2MQTT. Для проверки экрана понадобятся только два числа. Для постоянного обновления настроим одну автоматизацию в Home Assistant.

## Включить EXT1 и проверить экран

1. В Home Assistant откройте **внешний датчик температуры** и запишите его текущие показания в °C и %.
2. В Zigbee2MQTT откройте **Устройства → датчик-sonoff-snzb-02rd2 → Свойства**. Коротко нажмите заднюю кнопку устройства с экраном, чтобы разбудить его.
3. В блоке **Remote source status** нажмите **using**. На первом скриншоте выделена нужная кнопка. Рядом видно исходное состояние **unbound**.
4. Введите температуру в поле **Source 1 temperature** под ползунком, затем влажность в **Source 1 humidity**. Подтвердите ввод каждого числа. Например, для показаний с фотографии введите `27.9` и `41`.

![Выбор using и поле ввода температуры первого источника](assets/images/sonoff-snzb-02dr2/enable-temperature.webp "Включите using и введите температуру в выделенное поле с °C.") ![Поле ввода влажности первого источника над настройками статуса](assets/images/sonoff-snzb-02dr2/humidity.webp "Введите влажность в выделенное поле со знаком процента.")

Ещё раз коротко нажмите заднюю кнопку. Сверьте обе строки **EXT1** с введёнными числами. При обычной работе дисплей обновляет внешние показания примерно каждые 30 минут. Нажатие кнопки позволяет увидеть результат сразу. [Описание режима внешнего дисплея в Zigbee2MQTT](https://www.zigbee2mqtt.io/devices/SNZB-02DR2.html#displaying-readings-from-an-external-sensor)

## Найти четыре сущности в Home Assistant

Откройте **Настройки → Устройства и службы → Устройства**. Выберите устройство, нажмите на нужное показание или числовое поле, затем на шестерёнку и скопируйте **ID сущности**. Повторите для каждой строки таблицы.

| Устройство в HA | Какое поле открыть | Пример ID для автоматизации |
|---|---|---|
| Внешний датчик температуры | Температура, °C | `sensor.external_temperature` |
| Внешний датчик температуры | Влажность, % | `sensor.external_humidity` |
| датчик-sonoff-snzb-02rd2 | Source 1 temperature | `number.sonoff_source_1_temperature` |
| датчик-sonoff-snzb-02rd2 | Source 1 humidity | `number.sonoff_source_1_humidity` |

Две сущности `sensor` сообщают показания. Две сущности `number` принимают числа для EXT1. Названия из таблицы условные — подставьте свои ID во всех местах в YAML.

## Создать автоматизацию

Откройте **Настройки → Автоматизации и сцены → Создать автоматизацию → Создать новую автоматизацию**. В меню **⋮** выберите **Редактировать в YAML**, вставьте пример и нажмите **Сохранить**. При изменении любого показания правило считывает текущие значения и записывает каждое доступное число в соответствующее поле дисплея. Если одна сущность временно недоступна, второе показание продолжит обновляться.

```yaml
alias: Внешний датчик температуры → экран SONOFF
triggers:
  - trigger: state
    entity_id:
      - sensor.external_temperature
      - sensor.external_humidity
    to: null
actions:
  - variables:
      temperature: "{{ states('sensor.external_temperature') }}"
      humidity: "{{ states('sensor.external_humidity') }}"
  - if:
      - condition: template
        value_template: >
          {{ is_number(temperature) and -20 <= (temperature | float) <= 60 }}
    then:
      - action: number.set_value
        continue_on_error: true
        target:
          entity_id: number.sonoff_source_1_temperature
        data:
          value: "{{ temperature | float | round(1) }}"
  - if:
      - condition: template
        value_template: >
          {{ is_number(humidity) and 0 <= (humidity | float) <= 99.9 }}
    then:
      - action: number.set_value
        target:
          entity_id: number.sonoff_source_1_humidity
        data:
          value: "{{ humidity | float | round(1) }}"
mode: queued
```

## Проверить передачу при изменении показаний

1. Разбудите SONOFF коротким нажатием кнопки. В меню **⋮** автоматизации нажмите **Выполнить действия**. Проверьте значения **Source 1 temperature** и **Source 1 humidity** во вкладке **Свойства** в Zigbee2MQTT.
2. Дождитесь изменения на внешнем датчике. Например, если в HA температура поднялась с **27,9 до 28,1 °C**, а влажность осталась **41 %**, после обновления в EXT1 должны появиться **28,1 °C и 41 %**. Крупные цифры продолжат показывать местные измерения.
3. Если значение застряло, откройте **Трассировки** автоматизации и проверьте последний вызов `number.set_value`. Если в свойствах Z2M уже видно новое число, коротко нажмите кнопку SONOFF и ещё раз посмотрите на EXT1.

## Что означают state и Source 2

**Source 1 humidity state** задаёт состояние канала влажности. Кнопка **online** меняет статус. Числовое показание записывается в **Source 1 humidity** строкой выше. Список устройств на этой странице отсутствует — выбор источника задают две сущности `sensor` в автоматизации.

![Кнопки unbound, online, offline и restored в блоке Source 1 humidity state](assets/images/sonoff-snzb-02dr2/humidity-state.webp "У кнопок состояния нет поля для выбора другого датчика.")

**Source 2** — отдельный слот для второго внешнего источника. Если на экране свойств видны поля ниже, прокрутите вверх, чтобы вернуться к первому слоту.

![Числовое поле Source 2 humidity для второго источника](assets/images/sonoff-snzb-02dr2/second-humidity.webp "Source 2 humidity принимает число для второго источника.") ![Кнопки статуса влажности второго источника](assets/images/sonoff-snzb-02dr2/second-state.webp "Source 2 humidity state управляет статусом второго источника.")
