Сбросьте пароль пользователя через локальную консоль Home Assistant. Для этого нужен физический доступ к устройству.

## Сброс пароля

1. Откройте CLI Home Assistant.
2. Выполните `ha authentication reset --interactive`.
3. Выберите пользователя, которому нужно изменить пароль.
4. Дважды введите новый пароль.
