ИБП подключается к серверу NUT, а Home Assistant получает от него заряд батареи, состояние питания и другие доступные показатели. Сначала проверьте совместимость своей модели; ниже приведены общая схема и пример для ExeGate SpecialPro Smart.

## 1. Проверка совместимости

1. Найдите производителя и модель в [списке совместимого оборудования NUT](https://networkupstools.org/stable-hcl.html).
2. Сверьте тип подключения, рекомендуемый драйвер и примечания к модели. Совпадение только названия производителя недостаточно.
3. Подключите ИБП по USB. В Home Assistant откройте **Настройки → Система → Оборудование → Всё оборудование** и найдите устройство. Запишите `ID_VENDOR_ID` и `ID_MODEL_ID`, если они доступны; USB-идентификаторы также можно посмотреть в журнале NUT с включённой опцией `list_usb_devices`.
4. Для Home Assistant в виртуальной машине передайте USB-устройство в эту машину.

Отсутствие модели в списке не доказывает несовместимость. Поищите обсуждение именно вашей модели и её USB-идентификаторов в проекте NUT, прежде чем выбирать драйвер.

## 2. Установка сервера NUT

Для Home Assistant OS установите **Network UPS Tools** из магазина дополнений. Если NUT уже работает на NAS или отдельном сервере, этот шаг можно пропустить и перейти к подключению интеграции.

В настройках дополнения укажите пользователя и пароль, имя ИБП и драйвер из списка совместимости. Пример ниже подходит только для устройств, использующих `usbhid-ups`:

```yaml
users:
  - username: ha_monitor
    password: "REPLACE_WITH_YOUR_NUT_PASSWORD"
    instcmds: []
    actions: []
devices:
  - name: ups
    driver: usbhid-ups
    port: auto
    config: []
mode: netserver
shutdown_host: false
```

Замените пароль на собственный, а драйвер — на подходящий вашей модели. Пример рассчитан на мониторинг и не предоставляет пользователю права выполнять команды управления ИБП.

Сохраните настройки, запустите дополнение и проверьте журнал. Драйвер должен обнаружить устройство и получать данные. В журнале также уточните установленную версию NUT: поддержка отдельных моделей зависит от версии.

## 3. Пример: ExeGate SpecialPro Smart

В исходной настройке использовался ExeGate SpecialPro Smart с USB-идентификаторами `0925:1234`. Для этого варианта применялся `nutdrv_qx`. Это пример для конкретного устройства, а не универсальная замена `usbhid-ups`.

В блоке `devices` конфигурации замените описание устройства:

```yaml
devices:
  - name: ups
    driver: nutdrv_qx
    port: auto
    config:
      - vendorid = 0925
      - productid = 1234
```

Сверьте идентификаторы со своим ИБП. Обсуждение совместимости этого USB-контроллера есть в [задаче проекта NUT](https://github.com/networkupstools/nut/issues/2125). Если установленная версия не поддерживает устройство, сначала проверьте обновления дополнения и примечания к драйверу.

## 4. Подключение к Home Assistant

1. На вкладке **Информация** дополнения NUT скопируйте его имя хоста. Для отдельного сервера используйте его адрес в своей сети.
2. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Network UPS Tools (NUT)**.
3. Укажите хост, порт `3493` и учётные данные, заданные на сервере NUT.
4. Проверьте появившиеся сущности. Набор показателей зависит от модели: некоторые ИБП не передают температуру, выходное напряжение или оставшееся время работы.

## 5. Карточка состояния

Замените имена сущностей на созданные вашей интеграцией. Удалите из карточки показатели, которых нет у вашего ИБП.

```yaml
type: entities
title: Состояние ИБП
show_header_toggle: false
state_color: true
entities:
  - entity: sensor.ups_status
    name: Статус
  - entity: sensor.ups_battery_charge
    name: Заряд аккумулятора
  - entity: sensor.ups_input_voltage
    name: Входное напряжение
  - entity: sensor.ups_output_voltage
    name: Выходное напряжение
  - entity: sensor.ups_load
    name: Нагрузка
```

## Если устройство не определяется

- **USB не виден:** проверьте кабель, питание и передачу USB в виртуальную машину.
- **Ошибка доступа к USB:** проверьте права доступа и журнал драйвера. Такая ошибка сама по себе не означает, что нужно сменить драйвер.
- **Драйвер запущен, но данных нет:** перепроверьте модель, USB-идентификаторы и поддержку в установленной версии NUT.
- **Home Assistant не подключается:** сверьте хост, порт, пользователя и пароль. Сервер NUT должен быть запущен и доступен из HA.

Эта инструкция настраивает мониторинг. Автоматическое завершение работы сервера при разряде батареи настраивается отдельно.
