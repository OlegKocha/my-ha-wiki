Варианты из заметки для случая, когда Home Assistant не может обратиться к сервису проверки паролей HIBP.

## fix в роутере keenetic

В исходном обходном решении использовалась ручная настройка разрешения имени. Ниже приведён условный адрес `192.0.2.53` — он служит примером и не является рабочим сервером.

Команды для настройки соответствия имени и адреса:

- `ip host www.api.pwnedpasswords.com 192.0.2.53`
- `ip host api.pwnedpasswords.com 192.0.2.53`

Для удаления второй записи использовалась команда `no ip host api.pwnedpasswords.com 192.0.2.53`.

## fix в HA

В консоли Home Assistant команда `ha security options --pwned=false` отключает проверку скомпрометированных паролей. Она меняет защиту системы, а не устраняет причину недоступности сервиса. Подробнее — в [описании проверки паролей Home Assistant](https://www.home-assistant.io/more-info/pwned-passwords/).

В исходной заметке также сохранён [разбор с изменением pwned.py](https://habr.com/ru/articles/983106/).
