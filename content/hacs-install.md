Установите HACS через терминал Home Assistant, затем подключите его к аккаунту GitHub.

## Установка Advanced SSH & Web Terminal

1. Откройте **Настройки → Дополнения → Магазин дополнений → Advanced SSH & Web Terminal** и установите дополнение.
2. Подготовьте SSH-ключ на компьютере. Если он уже создан, выведите публичную часть командой `cat ~/.ssh/id_rsa.pub`.
3. На вкладке **Конфигурация** дополнения добавьте публичный ключ в `authorized_key`.
4. На вкладке **Информация** включите показ в боковой панели и запустите дополнение.

## Установка HACS

1. Откройте терминал и выполните `wget -O - https://get.hacs.xyz | bash -`.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → HACS**.
4. Подтвердите необходимые согласия и перейдите к подключению аккаунта GitHub.
5. Откройте [страницу активации устройства](https://github.com/login/device), войдите в свой аккаунт и введите код, показанный HACS.
