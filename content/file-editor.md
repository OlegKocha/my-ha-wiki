File editor позволяет редактировать конфигурационные файлы Home Assistant через веб-интерфейс.

## Установка

1. В профиле пользователя включите **Расширенный режим**.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Дополнения → Магазин дополнений → File editor** и нажмите **Установить**.

## Настройка

Вкладка **Конфигурация**:

- Отключите **Enforce Basepath**, если нужен доступ за пределами базового каталога.
- В настройке **Git** удалите `.storage`, если хотите использовать этот каталог в выбранном сценарии.
- Сохраните изменения.

На вкладке **Информация** включите **Watchdog** и **Показ на боковой панели**, затем запустите дополнение.
