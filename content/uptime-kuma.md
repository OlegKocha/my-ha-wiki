Uptime Kuma проверяет внешний адрес Home Assistant и сохраняет историю доступности. Это помогает найти периодические ошибки подключения, включая HTTP 522.

> [!note] Настройте примеры под свою систему
> Замените условные адреса и имена объектов значениями из своего Home Assistant.


## Установка дополнения

1. Откройте **Настройки → Дополнения → Магазин дополнений** и найдите **Uptime Kuma** в Community Add-ons.
2. Установите дополнение и включите **Запуск при старте** и **Watchdog**.
3. Запустите его и откройте веб-интерфейс.
4. При первом входе создайте учётную запись.

## Мониторинг внешнего адреса

Нажмите **Add New Monitor** и заполните параметры.

| Параметр | Пример |
|---|---|
| Friendly Name | Home Assistant |
| Type | HTTP(s) |
| URL | `https://ha.example.com/` |
| Method | GET |
| Expected Status Code | 200–299 |
| Interval | 60 секунд |
| Retries | 2–3 |
| Timeout | 40–60 секунд |

Сохраните монитор и проверьте первый результат. Для HTTPS оставьте проверку сертификата включённой. При ошибке сертификата сначала разберитесь с его настройкой.

Дополнительно можно создать проверку DNS-записи и Ping роутера. Они помогут отделить проблему разрешения имени от недоступности самого узла.

## Подключение к Home Assistant

1. В Uptime Kuma откройте **Settings → API Keys → Add API Key** и создайте ключ.
2. В Home Assistant выберите **Настройки → Устройства и службы → Добавить интеграцию → Uptime Kuma**.
3. Укажите URL своего экземпляра Uptime Kuma и API-ключ.
4. Сохраните подключение и найдите объекты мониторов.

Подробности — в [официальной инструкции Home Assistant](https://www.home-assistant.io/integrations/uptime_kuma/). Старый [репозиторий HACS](https://github.com/meichthys/uptime_kuma) архивирован; его автор рекомендует встроенную интеграцию.

## Карточка на панели

Добавьте карточку с ручной настройкой. Имена объектов замените на фактические объекты ваших мониторов.

```yaml
type: glance
title: Мониторинг DDNS
entities:
  - entity: binary_sensor.uptimerobot_example_ha_ddns  # или как назовётся твой монитор
    name: Статус DDNS
  - entity: sensor.uptimerobot_example_ha_ddns_uptime
    name: Uptime %
  - entity: sensor.uptimerobot_example_ha_ddns_response_time
    name: Время ответа
show_state: true
```

## Если появляются ошибки

- Сравните время ошибки с историей монитора и доступностью Home Assistant по локальному адресу.
- Проверьте DNS, настройки внешнего доступа и работу прокси, если он используется.
- Настройте уведомления в Uptime Kuma, чтобы получать сообщение при изменении доступности.
